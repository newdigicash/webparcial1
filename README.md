# Parcial 1
Sistema para la gestion de alquiler de autos
## Configuración
- Tras descargar el fuente, ejecutar `docker compose up --build` o sino `docker-compose up --build` para configurar la libería PDO y luego levantar el servidor apache en el puerto **8080**
## Ejecución
- El proyecto se ejecuta en http://localhost:8080
- MySQL se ejectua en el puerto **3306**
- Adminer (UI para mysql) se ejecuta en http://localhost:8082

En caso de error, revisar la configuración en el archivo `docker-compose.yml`
